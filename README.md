# ✈️ 여행 체크리스트 (Holiday Checklist)

여행을 준비할 때 필요한 물품을 쉽고 빠르게 관리할 수 있는 모바일 최적화 안드로이드 체크리스트 앱입니다.

---

## 📱 주요 기능

### 1. 여행 기간 자동 계산 및 아이템 생성
* **박/일 자동 계산**: '숙박 일수(박)'를 입력하면 `여행 일수 = 숙박 일수 + 1` 공식에 따라 자동으로 여행 기간(예: `2박 3일`)이 계산됩니다.
* **👕 옷 카테고리 날짜별 자동 생성**:
  * 1박부터 N박까지 날짜별로 기본 4종(속옷, 양말, 상의, 하의)이 독립적인 체크 항목으로 자동 생성됩니다.
  * 사용자가 직접 추가한 옷(잠옷, 수영복 등)은 날짜별로 반복되지 않고 옷 카테고리 내 **'기타 옷'** 영역에 모아서 표시됩니다.
* **🛁 샤워도구 카테고리**:
  * 기본 세면도구 4종(세안제, 로션, 샴푸, 바디워시) 기본 제공
  * 숙박 일수(N)에 맞춰 **수건 1 ~ 수건 N**이 자동으로 생성됩니다.
  * 커스텀 샤워도구(칫솔, 치약 등) 자유롭게 추가/수정/삭제 가능
* **🎵 기타 카테고리**:
  * **'생리대'** 기본 항목이 기본으로 항상 포함됩니다.
  * 개인 소지품(충전기, 보조배터리, 지갑 등) 자유롭게 추가/수정/삭제 가능

### 2. 스마트 체크 및 실시간 자동 저장
* **체크박스 & 취소선**: 항목 체크 시 산뜻한 에메랄드 그린 체크와 함께 텍스트 취소선(line-through)이 적용됩니다.
* **실시간 자동 저장**: 별도의 저장 버튼을 매번 누르지 않아도 체크 상태 및 수정 사항이 로컬 스토리지에 즉시 안전하게 보존됩니다.
* **진행률 게이지**: 완료된 물품 비율(%)을 실시간 프로그레스 바로 확인할 수 있습니다.

### 3. 멀티 여행 관리 및 독립 데이터
* 여러 여행을 각각 독립된 네모난 카드 형태로 홈 화면에서 관리할 수 있습니다.
* **⚙️ 관리 화면**: 저장된 여행 목록 중 원하는 여행을 선택하여 일괄 또는 개별 삭제할 수 있으며, 삭제 전 확인 팝업을 제공합니다.
* 빈 화면 시 *"새로운 여행 체크리스트를 만들어 보세요!"* 안내 메시지가 표시됩니다.

## 📦 APK 빌드 및 설치 안내

### 1. GitHub Releases에서 다운로드
* 저장소의 [Releases](https://github.com/kang-yewon/holiday_checklist_apk/releases) 또는 Actions 아티팩트에서 최신 `app-debug.apk`를 바로 다운로드하여 안드로이드 기기에 설치할 수 있습니다.

### 2. 저장소 루트 파일
* [holiday-checklist.apk](./holiday-checklist.apk) (루트 경로에 디버그 APK가 함께 제공됩니다)

### 3. 로컬 직접 빌드 방법
```bash
# 의존성 설치
npm install

# 웹 앱 빌드 및 안드로이드 동기화
npm run build
npx cap sync android

# APK 빌드 (Windows)
cd android
.\gradlew.bat assembleDebug
```
